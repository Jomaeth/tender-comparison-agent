# AGENTS.md

This repo is one agent skill: supplier tenders (PDF) → like-for-like comparison → recommendation draft.

- Read `SKILL.md` and follow it exactly — rules, tool order, where to stop.
- Inputs live in `input/` (read-only). Write only under `outputs/`.
- Every number comes from the tools or is cited to a tender + item / note number. Estimates are labelled 估算.
- The award decision is a person's. You draft; you do not decide, and you do not contact bidders.
- Do not install packages, download anything, or ask for permission to do so. The tools adapt to whatever PDF reader / PDF writer is already present and say which one they used; if one reports a missing capability, continue with the fallback it names and mention it in your report.
- Reply in the user's language (廣東話 / 繁體中文 / English).
